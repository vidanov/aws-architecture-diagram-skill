# Icons: Allied Telesis isometric computer/server/network (bonus library for 3D diagrams)

Companion to aws-icons-3d.txt. Use when a 3D/isometric diagram needs a generic client device,
on-prem server, server rack, or network hardware icon with no AWS-specific equivalent in aws3d.

## Critical facts

- These are SVG images bundled inside draw.io, referenced by relative path. Style pattern:
  image;points=[];aspect=fixed;html=1;align=center;shadow=0;dashed=0;image=img/lib/allied_telesis/<category>/<File>.svg;
- Only renders correctly inside draw.io (web app, desktop, VS Code extension).
- Only use for generic hardware with no AWS-specific icon.

## When to use
Reach for Allied Telesis icons for: generic client devices, on-prem servers, server racks,
and network hardware (switches, APs, routers). Keep using aws3d for actual AWS services.
