# AWS Icons: 3D / Isometric (legacy aws3d library)

Use when the user asks for a 3D, isometric, or "AWS 3D" style diagram.
This is a real, separate stencil library built into draw.io: mxgraph.aws3d.*

## Critical facts

- Legacy pre-2019 icon set, frozen around 2015-2016. NOT maintained.
- Coverage is much smaller than aws4. Most modern services have NO icon here.
- Style prefix (prepend to every shape):
  verticalLabelPosition=bottom;html=1;verticalAlign=top;strokeWidth=1;align=center;outlineConnect=0;dashed=0;shape=mxgraph.aws3d.<name>;
- Shape names are camelCase: dynamoDb, internetGateway, NOT dynamodb, internet_gateway.
- No resIcon/resourceIcon wrapper — all standalone shapes via shape=mxgraph.aws3d.<name>
- Use edgeStyle=isometricEdgeStyle (with endArrow=block override) for connectors.

## Edge style

Use the native isometric edge style:
  edgeStyle=isometricEdgeStyle;endArrow=block;startArrow=none;html=1;
  edgeStyle=isometricEdgeStyle;endArrow=block;startArrow=none;html=1;elbow=vertical;

The elbow=vertical variant changes which axis bends first.

## Layout

- Arrange along an ascending isometric staircase (each node dx=+400, dy=-200 from previous)
- Icons are already 3D — do NOT add platform/pedestal shapes underneath
- Anchor icons by bottom-center on a shared ground line per step
- Keep the same title/legend/companion conventions as standard diagrams
